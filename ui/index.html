Go Live in Discord

Discord has no stream key / RTMP address for user accounts, so sharing your screen in a Discord server happens inside Discord itself: join a voice channel in the main VetCord window, then click Share Your Screen (Go Live) in Discord and pick your game. That works in VetCord exactly as in the official client.

No server yet? Click the + button at the bottom of Discord's server list and choose Create My Own to start a community server, then enable Community under Server Settings.

Live streaming setup — X & Rumble (direct RTMP multistream)

Pushes the same capture used for clipping to every enabled destination at once. Stream keys are encrypted on this PC (Windows DPAPI) and never shown again after saving. Live ingestion needs your own X/Rumble account keys — VetCord cannot verify them for you.
